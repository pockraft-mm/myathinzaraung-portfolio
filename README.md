# Mya Thinzar Aung Portfolio

A personal portfolio built with React, TypeScript, and Vite. The site includes an animated hero, selected projects, skills, education, and contact details.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Getting started

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Build and preview

```sh
npm run build
npm run preview
```

## Project structure

- `src/App.tsx` — app shell and scroll behavior
- `src/sections.tsx` — page sections and navigation
- `src/content.ts` — portfolio copy and project data
- `src/styles.css` — site styles and responsive layouts
- `src/components/ui/` — reusable interface components
- `public/` — images, logo, and downloadable files

The project uses regular CSS and does not currently require Tailwind CSS or shadcn/ui.
